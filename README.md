# AIContentMaker - AI-сервис генерации контента для Telegram

AIContentMaker - сервис для автоматизации создания контента в Telegram-каналах.
Позволяет снимать стиль с существующего канала, генерировать посты и формировать контент-планы с последующим автопостингом.

Подходит для маркетинга, личных брендов и команд, где важно регулярно публиковать контент без ручной рутины.

---

## Problem

Создание контента для Telegram-каналов требует времени и ресурсов:

* нужно регулярно придумывать темы
* соблюдать единый стиль
* планировать публикации
* контролировать регулярность

В результате контент либо выходит нерегулярно, либо требует участия отдельного специалиста.

---

## Solution

AI-сервис автоматизирует полный цикл работы с контентом:

* анализирует стиль существующего канала
* генерирует посты по брифу
* формирует контент-план на неделю
* автоматически публикует посты

Позволяет снизить ручной труд и масштабировать контент без увеличения команды.

---

## Key Features

* Снятие стиля с Telegram-канала (по ссылке или @username)
* Генерация постов в заданном стиле
* Генерация контент-плана (1–3 поста в день)
* Хранение планов и работа с ними
* Автопостинг по расписанию
* Telegram-бот как пользовательский интерфейс
* REST API для расширения и интеграций

---

## How it works

1. Пользователь подключает канал
2. Сервис анализирует стиль (через LLM)
3. Пользователь задаёт бриф или цель
4. Генерируется пост или план
5. Посты автоматически публикуются по расписанию

---

## Architecture

Telegram User → Bot (aiogram) → FastAPI backend → LLM (OpenAI)
↓
SQLite (планы, пользователи)
↓
Telegram Bot API (отправка постов)

## Быстрый старт (локально)

### 1. Клонирование репозитория

```bash
git clone <repo-url> ai-content-maker
cd ai-content-maker
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Переменные окружения

```bash
TELEGRAM_BOT_TOKEN=<твой_бот_токен>
OPENAI_API_KEY=<твой_api_key>
API_BASE_URL=http://127.0.0.1:8000
```

### 4. Запуск backend

```bash
uvicorn app.main:app --reload
```

### 5. Запуск бота

```bash
python -m bot.main
```

## Основные API

* `POST /v1/generate` — генерация поста
* `POST /v1/plan/generate` — генерация плана
* `POST /v1/plan/confirm` — сохранение плана
* `GET /v1/plan/current/{user_id}` — текущий план
* `POST /v1/autopost/next/{user_id}` — автопостинг

---

## Сценарий использования

1. `/connect_channel` — подключение канала и снятие стиля
2. `/post` — генерация поста
3. `/plan_week` — генерация плана
4. `/plan_status` — просмотр плана
5. `/autopost_demo` — отправка поста

---

## Автопостинг

После подтверждения плана:

* каждому посту назначается время
* фоновый воркер отслеживает расписание
* пост автоматически публикуется в канал

Требования:

* бот добавлен администратором канала
* канал привязан
* план подтверждён

---

## Хранение данных

Используется SQLite (`neuro_content.db`):

* User — пользователь и активный стиль
* ContentPlan — план контента
* PlanItem — отдельные посты

Стиль хранится отдельно (JSON/файлы).
